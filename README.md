# architecture-alexandrite

Проектная работа 6-го спринта: кейс компании «Александрит» (производство ювелирных украшений на заказ, онлайн-магазин, CRM и MES, интеграция через RabbitMQ, партнёрский API).

## Структура

| Директория | Файл с решением | Дополнительно |
| --- | --- | --- |
| Task1 | [Планирование: анализ, идентификация проблем и поиск решений](Task1/Планирование%20-%20анализ,%20идентификация%20проблем%20и%20поиск%20решений.md) | текущая и целевая архитектура (drawio, png) |
| Task2 | [Выбор и настройка мониторинга в системе](Task2/Выбор%20и%20настройка%20мониторинга%20в%20системе.md) | схема компонентов мониторинга |
| Task3 | [Архитектурное решение по трейсингу](Task3/Архитектурное%20решение%20по%20трейсингу.md) | схема с новыми компонентами (красным) и вариант с алертингом (зелёным) |
| Task4 | [Архитектурное решение по логированию](Task4/Архитектурное%20решение%20по%20логированию.md) | схема сбора логов, сравнение технологий |
| Task5 | [Архитектурное решение по кешированию](Task5/Архитектурное%20решение%20по%20кешированию.md) | диаграммы последовательности (Mermaid и png) |

Схемы лежат в папках `diagrams` рядом с решением: для C4-схем исходники в формате draw.io (`.drawio`) и картинки (`.png`), для диаграмм последовательности Mermaid в тексте и картинки. За основу C4-схем взята диаграмма контейнеров «Александрита» из условия задания.
